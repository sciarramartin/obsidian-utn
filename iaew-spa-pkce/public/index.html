Single Page Application (SPA)

Flujo OIDC Delegado: Authorization Code con PKCE (RFC 7636)

Identity Provider: Keycloak (dds-materia)
Client ID Público: spa-69650-martinsciarra
Auth Flow: PKCE (S256, sin secreto)

🔄 Fases del Protocolo PKCE en Tiempo Real

1

Generación PKCE

Genera code_verifier criptográfico y calcula code_challenge con SHA-256.

2

Redirección IdP

Envía usuario a Keycloak con code_challenge y code_challenge_method=S256.

3

Callback & Code

Keycloak valida sesión y redirige a /login-callback con un code temporal.

4

Intercambio Seguro

SPA envía code + code_verifier a /token. Keycloak verifica el hash.

5

Tokens Recibidos

Se emiten access_token, id_token y refresh_token JWT.

🔒

No hay sesión iniciada

Esta SPA es un cliente público. No posee contraseña ni secreto de cliente configurado. La seguridad de la delegación está 100% garantizada por el par criptográfico PKCE.
